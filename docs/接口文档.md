# 中小型社区超市销售管理系统 · 后端接口文档

**版本**：V1.0  
**基础路径**：`/api/v1`  
**数据格式**：JSON  
**编码**：UTF-8  

---

## 一、通用说明

### 1.1 请求规范

| 项目 | 说明 |
|------|------|
| Content-Type | `application/json` |
| 认证方式 | 请求头携带 `Authorization: Bearer <token>` |
| 分页参数 | `page`（页码，默认 1）、`page_size`（每页条数，默认 20） |
| 时间格式 | `YYYY-MM-DD HH:mm:ss` |
| 金额精度 | 统一使用 `DECIMAL(10,2)`，前端展示时不做二次计算 |

### 1.2 统一响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | number | 状态码：200 成功，400 参数错误，401 未认证，403 无权限，500 服务器异常 |
| message | string | 提示信息 |
| data | object/null | 响应数据 |

### 1.3 分页响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [],
    "total": 1286,
    "page": 1,
    "page_size": 20
  }
}
```

### 1.4 角色编码

| 编码 | 名称 | 说明 |
|------|------|------|
| owner | 店主 | 全功能权限 |
| cashier | 收银员 | 收银、会员管理 |
| stock | 库管员 | 商品、库存管理 |
| buyer | 采购员 | 采购、库存查看 |
| admin | 系统管理员 | 系统配置、日志查看 |

## 二、认证模块

### 2.1 用户登录

**POST** `/auth/login`

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| username | string | 是 | 登录账号 |
| password | string | 是 | 密码 |

**响应示例**：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": 1,
      "username": "xudianzhang",
      "real_name": "徐店长",
      "roles": ["owner"],
      "avatar": ""
    }
  }
}
```

**业务规则**：
- 连续密码错误 5 次，账号锁定 15 分钟
- 登录成功清除失败计数，更新最近登录时间和 IP

### 2.2 用户登出

**POST** `/auth/logout`

**响应示例**：

```json
{ "code": 200, "message": "已退出登录" }
```

### 2.3 获取当前用户信息

**GET** `/auth/me`

**响应示例**：

```json
{
  "code": 200,
  "data": {
    "id": 1,
    "username": "xudianzhang",
    "real_name": "徐店长",
    "phone": "13801234567",
    "roles": ["owner"],
    "permissions": ["prd.product.view", "prd.product.edit", "..."]
  }
}
```

**请求参数**：

|------|------|:---:|------|
| barcode | string | 是 | 商品条码（门店内唯一） |
| name | string | 是 | 商品名称 |
| spec | string | 否 | 规格 |
| unit | string | 否 | 计量单位，默认「件」 |
| category_id | number | 是 | 所属分类 ID |
| supplier_id | number | 否 | 默认供应商 ID |

- 条码在同一门店内唯一，重复录入返回错误

## 七、销售收银模块

### 7.1 交易列表

**GET** `/sales/trades`

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| keyword | string | 否 | 交易号 |
| cashier_id | number | 否 | 收银员 ID |
| status | string | 否 | 状态：normal / void / returned / partly_returned / holding |
| start_date | string | 否 | 开始日期 |
| end_date | string | 否 | 结束日期 |
| page | number | 否 | 页码 |

### 7.2 交易详情

**GET** `/sales/trades/{id}`

**响应包含**：主单信息 + 商品明细 + 支付明细。

### 7.3 收银结算

**POST** `/sales/trades`

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| session_id | number | 是 | 收银会话 ID |
| member_id | number | 否 | 会员 ID，散客为空 |
| items | array | 是 | 商品明细 |
| items[].product_id | number | 是 | 商品 ID |
| items[].quantity | number | 是 | 数量 |
| items[].unit_price | decimal | 是 | 成交单价 |
| items[].discount_amount | decimal | 否 | 该行优惠金额 |
| items[].promo_id | number | 否 | 命中的促销活动 ID |
| payments | array | 是 | 支付明细 |
| payments[].pay_method | string | 是 | 支付方式：cash / wechat / alipay / balance / bank |
| payments[].amount | decimal | 是 | 支付金额 |

**业务规则**：
- 交易号自动生成：S + 日期 + 流水号
- 扣减库存（条件更新，防止超卖）
- 写入库存流水
- 更新商品成本与库存汇总
- 如使用储值支付：扣减会员余额，写资金流水
- 累加会员积分，写积分流水
- 更新会员消费统计
- 全部操作在单一事务中完成

### 7.4 交易作废

**PUT** `/sales/trades/{id}/void`

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| reason | string | 是 | 作废原因 |

**业务规则**：回增库存、回退会员余额、更新交易状态、写操作日志。

### 7.5 退货受理

**POST** `/sales/returns`

**请求参数**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| trade_id | number | 是 | 原交易单 ID |
| return_type | string | 是 | full 整单 / part 部分 |
| return_reason | string | 是 | 退货原因 |
| items | array | 是 | 退货明细 |
| items[].trade_item_id | number | 是 | 原销售明细 ID |
| items[].quantity | number | 是 | 退货数量 |

**业务规则**：
- 退货单号自动生成：TH + 日期 + 流水号
- 退货数量 ≤ 原购买数量 − 已退数量
- 回增库存、写库存流水
- 更新原交易状态
- 退款、扣回积分

### 7.6 挂单列表

**GET** `/sales/hold-orders`

| 字段 | 类型 | 必填 | 说明 |
