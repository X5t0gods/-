## 二、Bug 详情与修复

### Bug #1：系统参数"收银员最大折扣"浮点精度问题

| 项目 | 内容 |
|------|------|
| **严重程度** | 中等 |
| **发现位置** | 系统管理 → 参数配置 |
| **问题描述** | "收银员最大折扣"字段显示值为 `0.8999999761581421`（而非预期的 `0.90`），且输入框出现红色边框提示无效状态 |
| **复现步骤** | 登录店主账号 → 系统管理 → 参数配置 → 查看"收银员最大折扣"字段 |
| **原因分析** | JavaScript 浮点数精度问题，`Number('0.9')` 在内部存储为 `0.8999999761581421` |
| **修复方案** | 在 `initConfig()` 函数中对小数进行四舍五入处理 |
| **修改文件** | `src/views/system/index.vue` |
| **修复状态** | ✅ 已修复 |
